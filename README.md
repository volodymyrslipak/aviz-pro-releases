# AVIZ PRO for Mac — releases

Signed and notarized builds of **AVIZ PRO**, the native Mac app for music visuals by [AVIZ.STUDIO](https://aviz.studio).
This repository holds only release files (`.dmg` and `.sha256`); there is no source code here.

- Requirements: Apple silicon, macOS 14.2 or later.
- Updates: the app checks for new versions itself (Sparkle, signed with EdDSA).
- Licence: one-time purchase on [aviz.studio](https://aviz.studio). Without a licence key the app runs with a watermark on exports and outputs.
- Support: hi@aviz.studio
